# MerchantOS v6.1 — Visual finish

## Scope
Refined the authenticated merchant workspace visual system while preserving its existing routes, labels, data flows, API calls, and product behavior.

## Direction
High-tech operations infrastructure expressed through editorial industrial design: ink-black navigation, mineral-paper workspace, restrained acid-lime action color, fine rules, tabular numerals, and compact operational typography. No AI-gradient motifs, glowing cards, synthetic assistant avatars, or decorative chart noise.

## Changes
- Replaced the blue/white generic SaaS palette in the authenticated workspace with the committed MerchantOS ink/paper/lime palette.
- Tightened navigation, selected states, environment indicator, table surfaces, panel hierarchy, and action controls.
- Introduced consistent square-cornered operational controls and clearer data typography.
- Improved focus visibility, text selection, and reduced-motion handling.
- Added responsive adjustments for the compact navigation and metric layout.

## Verification
- CSS and TSX source were inspected.
- Full frontend production build was not run: `node_modules` is absent in this environment. Install dependencies and run `npm run build` before release.
- Browser screenshots and interaction QA were not available in this environment.
- No backend or financial behavior was changed.
